Frequently Asked Questions

What is OpsCat?

OpsCat is a server management app for iOS. It lets you monitor server performance, connect via SSH, manage Docker containers, browse files with SFTP, and run batch commands — all from your phone.

Is OpsCat free?

Yes! All features are free for up to 2 servers. If you need to manage more servers, a one-time purchase unlocks unlimited servers — no subscriptions.

What servers are supported?

OpsCat works with any Linux server accessible via SSH — cloud VPS (AWS, DigitalOcean, Vultr, Linode, etc.), dedicated servers, Raspberry Pi, home servers, and more.

Is my data secure?

Absolutely. All SSH credentials are encrypted and stored locally on your device. Cloud sync uses your private iCloud account. No data is ever sent to third-party servers.

Does it need anything installed on my server?

No. OpsCat only requires standard SSH access. No agents, daemons, or dependencies need to be installed on your server.

How do I restore my purchase?

Go to Settings inside the app and tap 'Restore Purchase'. Make sure you're signed in with the same Apple ID you used for the original purchase.
