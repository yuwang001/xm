Frequently Asked Questions

Does MobilePy require an internet connection?

No. Python code runs entirely on your device. An internet connection is only needed for installing additional pip packages.

Which Python version is included?

MobilePy embeds CPython 3.12, providing full native Python execution.

What packages are pre-installed?

NumPy, Pandas, Matplotlib, Pillow, and 10+ other C-extension packages are included. You can install additional pure-Python packages using pip.

How do I restore my subscription?

Go to Settings in the app, tap "Get MobilePy Pro", then tap "Restore Purchases" at the bottom of the paywall screen.

How do I cancel my subscription?

Subscriptions are managed through Apple. Go to iPhone Settings > Apple ID > Subscriptions to manage or cancel your subscription.
